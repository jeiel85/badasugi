How it works

말이 멈추는 순간,
글자가 됩니다.

긴 녹음이 끝나길 기다리지 않아요. 발화 단위로 잘라 바로 처리하는 실시간 파이프라인입니다. 스크롤하며 소리가 글자가 되는 과정을 따라가 보세요.

01

소리 듣기

마이크와 PC 소리를 한꺼번에 받아요. Zoom · Teams · Meet 상대방 목소리까지 — 가상 오디오 장치는 필요 없어요.

WASAPI 루프백마이크 + 시스템
02

발화 자르기

32ms마다 말소리인지 판단해, 말이 멈추는 순간 한 덩어리로 잘라 바로 다음 단계로 넘깁니다.

Silero VAD v632ms 프레임
03

누구인지 알아보기

발화마다 목소리 특징을 뽑아 사람을 나눠요. 쉼 없이 말을 이어받아도 문장 안에서 화자가 바뀌는 지점을 찾아 쪼갭니다. 이름을 붙여 둔 목소리는 다음 회의에서 알아봐요.

정리하기

FAQ

자주 묻는 질문

정말 무료인가요?

네. MIT 라이선스 오픈소스입니다. 로컬 모드는 비용이 전혀 들지 않고, API 모드를 쓸 때만 각 사에 사용량만큼 요금이 나갑니다. 앱 안에서 이 앱으로 쓴 API 사용량을 금액(원 · 달러)으로 확인할 수 있어요.

웹앱인가요, 설치 프로그램인가요?

설치형 Windows 프로그램입니다. 설치하면 시작 메뉴·바탕 화면에 받아쓰기가 생기고 badasugi.exe로 실행돼요. 브라우저나 인터넷 없이 동작하며, 화면만 Windows에 기본으로 들어 있는 WebView2로 그려서 설치 파일이 13MB 정도로 가볍습니다. 처음 실행할 때 음성 인식 모델(약 574MB)과 화자 모델(28MB)을 한 번만 받으면 이후 오프라인으로 동작해요.

어떤 PC에서 돌아가나요? GPU가 필요한가요?

Windows 10/11 64비트, AVX2를 지원하는 CPU(2013년 이후 대부분)면 됩니다. GPU는 없어도 됩니다. 로컬 모드의 속도는 CPU 성능에 따라 달라서, 사양이 낮은 노트북이라면 Groq API(매우 빠르고 저렴)를 추천합니다.

설치하면 "Windows의 PC 보호" 경고가 떠요.

코드 서명 인증서가 없는 개인 오픈소스 앱이라 SmartScreen이 경고합니다. 추가 정보 → 실행을 누르면 설치됩니다. 걱정되면 소스를 직접 빌드할 수 있어요.

온라인 회의(Zoom · Teams · Meet)도 받아 적을 수 있나요?

입력을 마이크 + 시스템으로 바꾸면 내 목소리와 상대방 목소리를 함께 받아 적습니다. 스피커 소리가 마이크로 다시 들어가면 중복될 수 있어 헤드셋을 권장합니다.

AI 요약은 어떤 걸로 하나요? 앱에 들어 있나요?

가볍게 유지하려고 LLM을 앱에 넣지 않았어요. 설정에서 Groq · Gemini(무료 등급), Claude, OpenAI, 또는 PC에 설치한 Ollama(인터넷 불필요) 중 하나를 고르면 됩니다. 키를 넣고 "연결 확인"을 누르면 쓸 수 있는 모델 목록까지 불러와요. 긴 회의는 구간으로 나눠 메모한 뒤 합쳐 회의록을 만듭니다.

화자 구분이 틀리면 어떻게 하나요?

녹음이 끝나면 앱이 회의 전체를 다시 듣고 한 번 더 정리해요(둘로 나뉜 같은 사람 합치기 · 잘못 붙은 문장 옮기기). 그래도 틀린 곳은 화자 칩을 눌러 다른 화자와 합치기, 본문 화자 이름을 눌러 이 문단의 화자 바꾸기로 바로 고칠 수 있어요. 미리 조절하려면 설정의 구분 민감도를 쓰고, 참석 인원을 알면 최대 화자 수를 지정하는 게 가장 정확합니다.

업데이트는 어떻게 하나요?

자동입니다. 새 버전을 백그라운드에서 받아 두었다가 녹음 중이 아닐 때 서명을 확인하고 적용해요. 창을 보고 있다면 위쪽 배너의 자세히 보기로 바뀐 내용을 확인하고 지금 적용을 누르면 됩니다.

macOS · Linux는 지원하나요?

지금은 Windows만 공식 지원합니다. 코어 엔진은 크로스플랫폼(Rust)이라 추후 확장할 수 있도록 만들어 두었습니다.
