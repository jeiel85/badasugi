Features

군더더기 없이,
회의에 필요한 것만.

녹음 버튼 하나. 나머지는 받아쓰기가 알아서 합니다.

누가 말했는지 자동으로

발화마다 목소리 특징(화자 임베딩)을 뽑아 실시간으로 사람을 구분합니다. 쉼 없이 말을 이어받아도 문장 안에서 화자가 바뀌는 지점을 찾아 나눠요. 이름을 누르면 "화자 1"을 "김 팀장"으로 바로 바꾸고, 잘못 나뉜 화자는 한 번에 합칠 수 있어요.

김 팀장출시일은 15일로 잡고, 목요일에 한 번 더 점검합시다.
이 개발결제 모듈은 금요일까지 배포 가능합니다.
박 디자인온보딩 시안은 수요일까지 드릴게요.

한국어에 강한 인식

Whisper large-v3 turbo 기반. 용어집에 회사·제품 이름을 넣으면 고유명사도 정확하게. 유튜브식 환각 문구("시청해 주셔서…")는 걸러냅니다.

로컬 또는 API, 내가 선택

민감한 회의는 PC 안에서만. 빠르게 필요하면 Groq · OpenAI API. 클릭 한 번으로 바꿔요.

트레이에 숨어 있다가 원클릭

러스트 + Tauri로 만든 가벼운 앱. 창을 닫아도 트레이에 머물고, 단축키 한 번으로 어디서든 녹음 시작·중지. 미니 창으로 줄이면 녹음 버튼과 방금 받아 적은 한 줄만 작업 표시줄 시계 위에 떠 있어요.

AI 회의록 요약

한 줄 요약 · 결정 사항 · 할 일(담당자/기한)에 회의 제목까지. 무료 등급이 있는 Groq · Gemini부터 Claude · OpenAI, PC 안에서만 도는 Ollama(EXAONE)까지.

온라인 회의도 그대로

마이크와 PC 소리(WASAPI 루프백)를 함께 받아 Zoom · Teams · Meet 상대방 목소리까지 받아 적습니다. 별도 가상 오디오 장치가 필요 없어요.

자동 저장 · 어디로든 내보내기

말하는 동안 계속 저장돼 앱이 꺼져도 안전합니다. 잘못 들린 단어는 더블클릭해서 바로 고치고, 원하는 형식으로 내보내세요.

.md회의록 · 요약 포함
.txt메모장 · 메신저 공유
.srt영상 자막
.json원본 데이터

녹음 파일도 끌어다 놓기

휴대폰·Zoom으로 녹음해 둔 mp3 · m4a · mp4 · wav를 창에 놓으면 화자를 나눠 받아 적습니다.

필요한 건 다 있게

문장을 누르면 그 부분 다시 듣기, 오프 더 레코드 일시정지, 지난 회의 전체 검색, 녹취록 안 Ctrl+F, 글자 크기 조절, 화면 가장자리에 자석처럼 붙는 창, 마이크 무음·연결 끊김 알림.

알아서 최신 버전

새 버전을 조용히 받아 두었다가, 쓰지 않을 때 서명을 확인하고 적용합니다. 다시 설치할 일이 없어요.

글자로 옮기기

FAQ

자주 묻는 질문

정말 무료인가요?

네. MIT 라이선스 오픈소스입니다. 로컬 모드는 비용이 전혀 들지 않고, API 모드를 쓸 때만 각 사에 사용량만큼 요금이 나갑니다.

웹앱인가요, 설치 프로그램인가요?

설치형 Windows 프로그램입니다. 설치하면 시작 메뉴·바탕 화면에 받아쓰기가 생기고 badasugi.exe로 실행돼요. 브라우저나 인터넷 없이 동작하며, 화면만 Windows에 기본으로 들어 있는 WebView2로 그려서 설치 파일이 13MB 정도로 가볍습니다.

어떤 PC에서 돌아가나요? GPU가 필요한가요?

Windows 10/11 64비트, AVX2를 지원하는 CPU(2013년 이후 대부분)면 됩니다. GPU는 없어도 됩니다. 로컬 모드의 속도는 CPU 성능에 따라 달라서, 사양이 낮은 노트북이라면 Groq API(매우 빠르고 저렴)를 추천합니다.

설치하면 "Windows의 PC 보호" 경고가 떠요.

코드 서명 인증서가 없는 개인 오픈소스 앱이라 SmartScreen이 경고합니다. 추가 정보 → 실행을 누르면 설치됩니다. 걱정되면 소스를 직접 빌드할 수 있어요.

온라인 회의(Zoom · Teams · Meet)도 받아 적을 수 있나요?

입력을 마이크 + 시스템으로 바꾸면 내 목소리와 상대방 목소리를 함께 받아 적습니다. 스피커 소리가 마이크로 다시 들어가면 중복될 수 있어 헤드셋을 권장합니다.

AI 요약은 어떤 걸로 하나요? 앱에 들어 있나요?

가볍게 유지하려고 LLM을 앱에 넣지 않았어요. 설정에서 Groq · Gemini(무료 등급), Claude, OpenAI, 또는 PC에 설치한 Ollama(인터넷 불필요) 중 하나를 고르면 됩니다. 키를 넣고 "연결 확인"을 누르면 쓸 수 있는 모델 목록까지 불러와요.

업데이트는 어떻게 하나요?

자동입니다. 새 버전을 백그라운드에서 받아 두었다가 녹음 중이 아닐 때 서명을 확인하고 적용해요. 창을 보고 있다면 위쪽 배너의 지금 적용을 누르면 됩니다.

화자 구분이 틀리면 어떻게 하나요?

받아 적은 뒤에도 화자 칩을 눌러 다른 화자와 합치기, 본문 화자 이름을 눌러 이 문단의 화자 바꾸기로 바로 고칠 수 있어요. 미리 조절하려면 설정의 구분 민감도를 쓰세요. 한 사람이 여러 명으로 나뉘면 왼쪽(적게)으로, 여러 명이 한 사람으로 합쳐지면 오른쪽(많게)으로 옮기면 됩니다. 참석 인원을 알면 최대 화자 수를 지정하는 게 가장 정확합니다.

macOS · Linux는 지원하나요?

지금은 Windows만 공식 지원합니다. 코어 엔진은 크로스플랫폼(Rust)이라 추후 확장할 수 있도록 만들어 두었습니다.
